# ECB reference quotes: 2026-10-05 snapshot

This repository preserves one dated European Central Bank euro foreign exchange
reference rate snapshot: **2026-10-05, 29 quote currencies, EUR base**. It is a
source fixture for future OVDB publication. Public query availability, Directory
admission and semantic model/meaning bindings are pending review and validation.

Source: **European Central Bank (ECB)**. The original rates are available
**free of charge** from [the ECB XML download](https://www.ecb.europa.eu/stats/eurofxref/eurofxref-daily.xml).
That daily link changes over time; the committed XML preserves this dated input.
The [ECB reference page](https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html)
describes the rates as informational and strongly discourages transaction use.

One native recordset, `FxReferenceQuote`, has key
`(ReferenceDate, QuoteCurrencyCode)`. All fields are SQLite TEXT and JSON strings:

| Field | Meaning |
| --- | --- |
| ReferenceDate | Source reference calendar date, `2026-10-05` |
| BaseCurrencyCode | Explicit EUR base |
| QuoteCurrencyCode | Exact source quote currency code |
| Rate | Positive exact decimal lexeme: quote currency units per one EUR |
| RateRaw | Unchanged source XML decimal spelling, e.g. GBP `0.84720` |
| RateKind | ECB indicative reference |
| Provider | ECB |

`Rate` has a decimal lexical contract while its wire/storage type is text. The
fixture performs no floating point conversion or arithmetic. ReferenceDate does
not claim an actual publication instant. Fetch time and HTTP Last-Modified are
separate provenance. There is no native EUR identity row, other date, missing-day
fill or non-EUR derived quote. This repository makes no current, refreshed or
full-history coverage claim.

The transformation is XML restructuring into sorted rows and one SQLite table;
EUR and the reference kind are explicit. Source decimal values remain unchanged.
The [JSON rows](artifacts/ecb-2026-10-05/native/FxReferenceQuote.json) and
[SQLite database](artifacts/ecb-2026-10-05/native/ecb.sqlite) are small, uncompressed
artifacts, so no chunk reconstruction is needed.

```sh
python3 scripts/import_ecb.py
python3 scripts/import_ecb.py --check
python3 -m unittest discover -s tests -v
```

Generation is offline and accepts only the hash-pinned XML and captured terms.
`--check` compares every generated byte, including SQLite. Packaging clears the
informational SQLite header writer-version bytes 96-99; format versions, counters
and all source rows stay intact. Different SQLite
versions must pass that exact byte comparison; a runtime difference is not
permission to silently change the committed artifact. The snapshot receipt pins
the converter bytes without embedding a self-referential commit. Once committed,
local evidence references inherit that immutable provider commit.

The [source receipt](source/artifact-snapshot.json) and
[fetch receipts](source/fetch-receipts.json) record original URLs, captures,
input/output hashes and byte counts. [DATA-LICENSE.md](DATA-LICENSE.md) explains
source terms; [metadata/source-rights.json](metadata/source-rights.json) carries
the closed `ovdb-source-rights/1` notices and pins.
[metadata/data-rights-profile.json](metadata/data-rights-profile.json) is a
prepared database-scoped `ovdb-data-rights/1` block, not an opted-in Publisher
manifest or declaration that the shared Cloud server licenses every database.

The conventional candidate identity is `ingitdb/ecb-ingitdb`, local database id
`ecb`, native recordset `FxReferenceQuote`. Future hosting would use
`https://cloud.openvaultdb.com/ovdb/dbs/ecb`. Publication needs the reviewed
model/meaning tuple, released new descriptor schemas and validators, live tolerant
readers, immutable provider pins, generated runtime equality, actual read-only
HTTP/DataTug acceptance and independent review. Root owns that admission gate;
this source fixture does not grant it.
